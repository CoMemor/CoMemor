Questions, answered straight.

          
Everything you need to know about CoMemor's local
            memory architecture and security model.

        

        

          

            
            

              

                
CoMemor runs as a standard Model Context Protocol (MCP) server. You add npx comemor to
                  your host's MCP configuration (such as ~/.cursor/mcp.json,
                  claude_desktop_config.json, or .vscode/mcp.json). When your AI coding
                  assistant encounters a build, test, or runtime error, it calls find_fix to look up prior
                  fixes and record_failure once the issue is resolved.
                

              

            

          

          

            
            

              

                
No. CoMemor is 100% local-first with zero external telemetry or cloud dependencies. All memories are
                  stored directly in your project under .agent-memory/records.jsonl. Before storing, regex
                  patterns and Shannon entropy scans automatically redact API keys, tokens, and credentials.

              

            

          

          

            
            

              

                
Vector databases rely on probabilistic semantic embeddings that can drift, hallucinate false
                  associations, and introduce heavy Python or remote API dependencies. CoMemor uses deterministic
                  SHA-256 error fingerprinting combined with SQLite FTS5 lexical token matching. It is deterministic,
                  explainable, fast, and runs entirely in local Node.js.

              

            

          

          

            
            

              

                
Never. CoMemor enforces a strict non-executing MCP contract. The verify_fix tool
                  validates dry-run command safety and policy constraints, returning structured suggestions with
                  executedByServer: false. The host environment and human engineer always retain full
                  execution control.
                

              

            

          

          

            
            

              

                
CoMemor exposes four core MCP tools: find_fix (retrieves relevant verified solutions),
                  record_failure (persists a validated error-fix pair), verify_fix (checks
                  proposed fix safety against policy), and list_memory_stats (reports repository memory
                  health and counts).
                

              

            

          

          

            
            

              

                
Seven heuristic detectors scan records. Flagged ones are quarantined in
                  .agent-memory/quarantine.jsonl, and all retrieved records are returned wrapped in strict
                  untrusted-data delimiters to prevent instruction hijacking.
                

              

            

          

          

            
            

              

                
Yes. Memories are stored in plain text JSONL at .agent-memory/records.jsonl. You can
                  inspect, version control, or edit them with any text editor, or launch the built-in local web
                  dashboard via npx comemor-dashboard to explore memory stats, search queries, and approval
                  logs.

              

            

          

          

            
            

              

                
Node.js ≥ 22.5. Run npx comemor. No install, no account, no cloud.
